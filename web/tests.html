Reproduce these results

Install the optional observation dependencies, download the versioned sources, then run the pipeline. This requires several GB of disk space. It does not need MCD.

pip install -e '.[observations]'
python scripts/data/acquire.py --large
python scripts/data/build.py
python scripts/data/build_evidence.py
pytest -q -m 'not integration'

The output JSON records input-manifest and analysis-code checksums. The figures and data shown here are a saved run, not a new calculation triggered by opening this page.
