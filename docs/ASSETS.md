# Visual assets

`web/images/mars-viking.jpg` is the **Mars Planet Globe** mosaic published by NASA, credited to **NASA/JPL-Caltech**. It is used as a decorative backdrop, separate from the numerical wind maps. The source describes an enhanced mosaic assembled from Viking Orbiter images and projected into a spacecraft-like view.

- [Source and credit](https://science.nasa.gov/resource/mars-planet-globe/)
- [NASA media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)

The file is served locally without a third-party request on page load. Its credit is visible in the interface. It is not a map of the selected altitude or season, and NASA/JPL-Caltech does not endorse this personal project. The application's MIT licence does not relicense this external asset.

Map colours are generated from MCD values. The sequential palette uses a dark-to-light rust/amber ramp; signed fields use a purple-to-rust diverging ramp. Animation and MP4 export share the same scale limits over the entire sequence. Arrows encode wind direction, not moving parcels.
