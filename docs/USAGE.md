# Using the dichotomy research site

Start the server as described in [README](../README.md), then open `http://127.0.0.1:8765`. The five main navigation links stay in the same order on every page. The active section is highlighted.

1. **Home** explains the question and offers three starting points. Use it to return to the overall project.
2. **Compare** confronts four origin families with common observations. Filter by evidence type or display one scenario; open a cell for its source, limits and next test. The chronology is the second view on the same page. Filter a sample or event type, and change the time window to separate recent ejections. Unknown ages remain off the numeric axis.
3. **Data** groups maps, meteorites, laboratory magnetism, water/alteration and provenance. Begin with relief, then change the layer. Candidate source craters are not confirmed launch sites.
4. **Study** contains five sequential chapters: question, regions, histories, method, results. Previous/next links guide the reading. The results lead to the completed diagnostic calculations.
5. **Sources** initially shows the core reading route, rather than the entire discovery inventory. Search titles, authors, DOI and notes; open additional filters as needed. Reading-depth labels tell you whether metadata, an abstract or selected sections were consulted. The RIS export matches the current library filters.

The comparison CSV downloads contain the **complete curated tables**, regardless of display filters, and retain source URLs and uncertainty conventions. This differs intentionally from the filtered RIS export. Notes can be read as HTML or downloaded as Markdown.

On mobile, display one scenario for a narrower table. The full comparison also scrolls horizontally within its own frame. Maps and scientific tables retain their detailed controls; reading summaries precede them.

The website no longer contains atmospheric modeling or MCD calculation endpoints. No atmospheric installation is needed to open the research collection, chronology, observations or saved study. The launcher does not compile MCD. Historical offline numerical work remains subject to the [source policy](SOURCE_POLICY.md).
